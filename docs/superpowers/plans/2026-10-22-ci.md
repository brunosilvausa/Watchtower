# Watchtower CI execution

Scope: user-authorized GitHub Actions only; commit/push and watch the run. No deployment, provider setup, repository protections, force push or third-party service installation.

## Acceptance criteria

- [x] Pushes and pull requests to main trigger a pinned, frozen-install workflow.
- [x] Quality, PostgreSQL/production browser and development showcase checks use separate disposable environments.
- [x] Failure artifacts contain only allowlisted outcomes and test locations; privacy self-check passes.
- [ ] Workflow syntax and full local quality checks pass.
- [ ] Commit and push, then verify the actual GitHub run and fix failures.

## Files

- `.github/workflows/ci.yml`: triggers, permissions, isolated jobs, failure artifacts.
- `.github/actions/setup/action.yml`: shared pinned toolchain/frozen installation.
- `scripts/ci-report.mjs`, `scripts/ci-report.test.mjs`: privacy-preserving failure summary and self-check.
- `.gitignore`, `README.md`, `docs/ci.md`: local report exclusion and reproducible operation.

Evidence and final run URL will be recorded in `docs/evidence/ci/validation.md`.
