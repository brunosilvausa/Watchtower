Pill label for monitor status, deltas, counts, and yellow "NEW" callouts.
```jsx
<Badge tone="up" dot>Operational</Badge>
<Badge tone="down" dot>Down</Badge>
<Badge tone="yellow">New</Badge>
<Badge tone="up">+1.10%</Badge>
```
Status tones use 12% tinted fills with full-strength text. Only `yellow` is uppercase by default.
