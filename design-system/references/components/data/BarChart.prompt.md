Discrete-period values (checks per day, incidents per week, net change). Bars grow from the zero line; negatives sit below it, so sign never relies on colour.
```jsx
<BarChart ariaLabel="Incidents per week" labels={['W36','W37','W38','W39']} data={[2, 0, null, 1]} comparison={[1, 3, 2, 2]} comparisonName="Last quarter avg" />
```
Keyboard: focus the chart, ←/→ to move, Esc to clear. A visually-hidden table carries every value.
